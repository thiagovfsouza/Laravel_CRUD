<div>
  <h2>📋 Funcionalidades</h2>
  <ul>
    <li>Autenticação de usuários (login/registro)</li>
    <li>CRUD completo de entidades básicas</li>
    <li>Estrutura MVC padrão do Laravel</li>
    <li>Rotas básicas de exemplo</li>
  </ul>

  <h2>🛠️ Tecnologias</h2>
  <h3>Backend</h3>
  <ul>
    <li>PHP 8.x</li>
    <li>Laravel Framework</li>
    <li>MySQL</li>
  </ul>

  <h3>Frontend</h3>
  <ul>
    <li>Bootstrap (opcional)</li>
    <li>Blade Templates</li>
  </ul>

  <h2>🚀 Começando</h2>
  <h3>Pré-requisitos</h3>
  <ul>
    <li>PHP >= 8.2</li>
    <li>Composer</li>
    <li>MySQL >= 5.7</li>
  </ul>

  <h3>Instalação</h3>
  <ol>
    <li>Clone o repositório
      <pre><code>git clone https://github.com/seu-usuario/laravel-test.git
cd laravel-test</code></pre>
    </li>
    <li>Instale as dependências
      <pre><code>composer install</code></pre>
    </li>
    <li>Configure o ambiente
      <pre><code>cp .env.example .env
php artisan key:generate</code></pre>
    </li>
    <li>Execute as migrações
      <pre><code>php artisan migrate</code></pre>
    </li>
    <li>Inicie o servidor
      <pre><code>php artisan serve</code></pre>
    </li>
  </ol>

  <h2>🧪 Executando os testes</h2>
  <pre><code>php artisan test</code></pre>

  <h2>📚 Estrutura do Projeto</h2>
  <ul>
    <li>Rotas em <code>routes/web.php</code></li>
    <li>Controladores em <code>app/Http/Controllers</code></li>
    <li>Modelos em <code>app/Models</code></li>
    <li>Views em <code>resources/views</code></li>
    <li>Migrações em <code>database/migrations</code></li>
  </ul>

  <h2>🤝 Contribuindo</h2>
  <ol>
    <li>Faça um fork do projeto</li>
    <li>Crie uma branch para sua feature (<code>git checkout -b feature/nova-feature</code>)</li>
    <li>Commit suas alterações (<code>git commit -m 'Adiciona nova feature'</code>)</li>
    <li>Push para a branch (<code>git push origin feature/nova-feature</code>)</li>
    <li>Abra um Pull Request</li>
  </ol>
